# 日常录音分析工具设计文档

## 1. 设计目标

构建一个**本地运行的日常录音分析工具**。用户将录音放入监控目录后，系统自动识别用户本人的声音，并针对该声音生成词句级别的分析报告，帮助发现并改进表达问题。

## 2. 核心架构

整体采用本地流水线架构，所有处理在本地完成，录音与声纹数据不上传云端。

![架构图](speaking-analysis-architecture.html)

主要组件：

| 组件 | 职责 | 关键技术 |
|------|------|----------|
| 文件夹监控器 | 监听 `input/` 目录，检测新增音频并触发流水线 | `watchdog` |
| 音频预处理 | VAD 去静音、降噪、按自然间断点切分 | silero-vad / RNNoise |
| 声纹注册 | 一次性录入用户 30-60 秒语音，提取声纹 | speechbrain / pyannote.audio |
| 说话人分离 | 将录音按说话人切分 | pyannote.audio |
| 用户语音筛选器 | 与注册声纹比对，只保留用户片段 | 余弦相似度 + 阈值 |
| ASR 转写 | 中英混合识别，输出带时间戳的词/句 | faster-whisper |
| 文本分析 | 填充词、重复词、长句、逻辑连接词 | 规则 + 分词 |
| 音频特征 | 语速、停顿、音量、发音清晰度 | librosa / pydub |
| 情感/语气 | 情绪类别与语气起伏 | emotion2vec |
| 发音标准 | 声调/音素偏差、ASR 置信度低标记 | pypinyin / phonemizer |
| 报告生成器 | 输出 Markdown + JSON 双格式报告 | Jinja2 / 模板 |

## 3. 关键决策

- **D1**: 分析维度 = 转写文本 + 情感/语气 + 发音清晰度 + 发音标准/正音 + 表达结构
- **D2**: 交互方式 = 文件夹监控 + 自动生成报告
- **D3**: 语言支持 = 中英混合
- **D4**: 历史追踪 = 保留原始报告文件，架构预留趋势聚合扩展点
- **D5**: 多人对话 = 预先录入声纹，分析时锁定用户声音并过滤其他说话人
- **D6**: 分析粒度 = 词句级别，附带时间戳
- **D7**: 声纹纠偏 = 报告标记低置信度片段，用户一键确认/否认，增量更新声纹
- **D8**: 长录音处理 = 按自然不说话间断点切分，片段大小在合理处理区间内可变
- **D9**: 发音标准/正音 = 结合 ASR 置信度和音素对齐标记具体字词或音素问题

## 4. 数据流

1. 用户将录音放入 `input/`
2. watcher 触发，preprocessor 进行 VAD / 降噪 / 切分
3. diarization 分离说话人，与用户声纹匹配
4. 只保留用户片段，送入 ASR 转写
5. 转写结果 + 音频特征 + 情感分析并行处理
6. 汇总各维度发现，生成报告到 `output/`
7. 低置信度说话人片段在报告中列出，用户可校正

## 6. 技术栈

- **语言**: Python 3.10+
- **ASR**: faster-whisper
- **声纹/说话人分离**: pyannote.audio / speechbrain
- **音频处理**: librosa, pydub, silero-vad
- **情感分析**: emotion2vec / transformers
- **发音/音素**: pypinyin, phonemizer
- **文件夹监控**: watchdog
- **报告输出**: Markdown + JSON
- **CLI**: Click

## 7. 报告示例（摘要）

```markdown
# 录音分析报告：recording_20260808.mp3

## 总体摘要
- 时长：32 分 15 秒
- 识别到的用户语音：18 分 42 秒
- 主要问题：填充词偏多、部分句子过长

## 详细发现

### 填充词
- 03:12 - 03:18：连续使用 3 次“然后”，建议替换为停顿或具体连接。

### 语速
- 平均语速：168 字/分钟
- 05:20 - 05:50 语速偏快（210 字/分钟），建议放慢。

### 发音标准 / 正音
- 05:12 “项目”的“项”疑似读成了轻声，建议确认声调。
- 11:08 英语单词 “specific” 音素 /ɪ/ 位置可能读错。
```

## 8. 非目标

- 首期不实现实时录音采集
- 不构建用户账户系统或多租户服务
- 不替代专业演讲教练的人工反馈
- 首期不实现趋势 Dashboard

## 9. 约束

- 优先本地处理，保护录音隐私
- 分析结果可解释，避免黑箱评分
- 声纹数据本地存储，不上传云端
