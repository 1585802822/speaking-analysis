# 日常录音分析工具实施计划

## 目标

实现一个本地运行的日常录音分析工具 MVP。用户将录音放入 `input/` 后，系统监控、预处理、识别用户声音、转写，并生成词句级别的 Markdown/JSON 分析报告到 `output/`。

## 任务清单

### T1: 项目骨架与配置
- [ ] 创建 `src/` 目录结构与空模块文件
- [ ] 创建 `config.yaml`：输入/输出/声纹目录、音频格式、VAD/切分/声纹/ASR/分析阈值
- [ ] 创建 `requirements.txt`：Python 依赖
- [ ] 创建 `README.md`：安装、注册、运行说明
- [ ] 创建 CLI 入口 `src/cli.py`：支持 `register`、`watch`、`analyze` 子命令

**验收标准**：`python -m src.cli --help` 能正常显示；配置加载无报错。

### T2: 文件夹监控
- [ ] 实现 `src/watcher.py`
- [ ] 使用 `watchdog` 监听 `input/`
- [ ] 过滤支持的音频格式（`.mp3`, `.wav`, `.m4a`, `.flac`）
- [ ] 避免重复处理已处理文件（通过输出文件或状态记录）
- [ ] 触发时调用完整分析流水线

**验收标准**：放入测试音频后 watcher 自动触发并生成对应报告。

### T3: 音频预处理
- [ ] 实现 `src/preprocessor.py`
- [ ] 加载音频为统一采样率（16 kHz 单声道）
- [ ] VAD：检测语音区间，去除长时间静音
- [ ] 降噪：轻量级降噪（如谱减法或 RNNoise）
- [ ] 切分：按自然停顿切分，片段 10 秒–5 分钟

**验收标准**：1–2 小时长录音被切成合理片段；含杂音录音的静音段被去除。

### T4: 声纹注册
- [ ] 实现 `src/enrollment.py`
- [ ] 加载注册音频并提取声纹嵌入
- [ ] 保存声纹到 `voiceprint/`
- [ ] 支持增量更新（正面/负面样本）

**验收标准**：运行 `python -m src.cli register <sample.wav>` 后 `voiceprint/` 出现声纹文件。

### T5: 说话人分离与匹配
- [ ] 实现 `src/diarization.py`：说话人分离
- [ ] 实现用户语音筛选逻辑（与注册声纹计算相似度）
- [ ] 设置相似度阈值（默认 0.75）和低置信度阈值（默认 0.55）
- [ ] 过滤非用户片段，保留用户语音

**验收标准**：多人对话测试音频中，只保留用户本人的语音片段；低置信度片段被标记。

### T6: ASR 转写
- [ ] 实现 `src/transcriber.py`
- [ ] 加载 faster-whisper 本地模型
- [ ] 支持中英混合识别
- [ ] 输出词/句级别时间戳
- [ ] 将转写结果与用户语音片段对齐

**验收标准**：示例录音能生成带时间戳的转写文本；中英混合内容识别正确。

### T7: 文本分析
- [ ] 实现 `src/text_analyzer.py`
- [ ] 填充词检测（中/英）
- [ ] 重复词/短语检测
- [ ] 长句检测（超过阈值字数/词数）
- [ ] 逻辑连接词统计
- [ ] 输出带时间戳的发现

**验收标准**：能指出具体时间点上的填充词、重复词和长句问题。

### T8: 音频特征分析
- [ ] 实现 `src/audio_analyzer.py`
- [ ] 语速计算（字/词每分钟）
- [ ] 停顿检测（过长停顿、频繁短停顿）
- [ ] 音量/能量变化分析
- [ ] 发音清晰度估计

**验收标准**：报告包含平均语速、异常语速区间、停顿问题、音量问题。

### T9: 情感/语气分析
- [ ] 实现 `src/emotion_analyzer.py`
- [ ] 加载 emotion2vec 或类似本地模型
- [ ] 识别情绪类别（中性、积极、紧张、疲惫等）
- [ ] 检测语气单调或情绪起伏不足

**验收标准**：示例录音能输出情绪标签和语气变化描述。

### T10: 发音标准/正音分析
- [ ] 实现 `src/pronunciation_analyzer.py`
- [ ] 基于 ASR 置信度标记低置信度词/字
- [ ] 普通话：结合拼音/声调检测疑似偏差
- [ ] 英语：结合音素对齐标记疑似错误
- [ ] 给出具体练习建议

**验收标准**：能标记具体字词或音素问题并给出可执行练习建议。

### T11: 报告生成
- [ ] 实现 `src/reporter.py`
- [ ] 汇总各维度发现
- [ ] 生成 Markdown 报告：摘要、评分、具体问题、时间戳、改进建议
- [ ] 生成 JSON 报告：结构化数据
- [ ] 报告文件名与录音文件名对应

**验收标准**：每个录音生成对应的 `.md` 和 `.json` 报告；问题定位到词句和时间戳。

### T12: 声纹纠偏闭环
- [ ] 在 Markdown 报告中为低置信度片段添加“这是我/这不是我”入口
- [ ] 实现确认/否认后的增量更新
- [ ] 重新计算用户声纹中心

**验收标准**：用户校正后，声纹模型在下次分析中更准确。

### T13: 端到端集成测试
- [ ] 准备示例录音（单人、多人、中英混合、长录音、含杂音）
- [ ] 运行完整流水线验证
- [ ] 验证报告内容符合预期
- [ ] 验证文件夹监控自动触发
- [ ] 验证声纹校正更新模型

**验收标准**：所有验收示例通过。

## 里程碑

1. **M1（T1–T3）**：项目骨架 + 监控 + 预处理可运行
2. **M2（T4–T6）**：声纹 + 转写链路打通
3. **M3（T7–T11）**：全部分析维度 + 报告生成
4. **M4（T12–T13）**：纠偏闭环 + 端到端验证

## 风险与依赖

- 本地模型体积大，首次下载耗时。
- pyannote.audio / speechbrain 对 GPU/内存有要求，CPU  fallback 需验证。
- 中英混合 ASR 的准确性需要实测调参。
- 发音标准/正音对英语音素分析依赖额外模型，首期可先基于 ASR 置信度实现中文部分。

## 下一步

完成 Plan 节点后进入 Execute 节点，按 M1 → M2 → M3 → M4 顺序实现代码。
