# Outcome

构建一个本地运行的日常录音分析工具。用户把录音放入监控目录后，系统自动识别用户本人的声音，并针对该声音生成词句级别的分析报告，帮助发现并改进表达问题。

# Scope

- 支持对日常录音进行自动化分析
- 录音中可能包含多人对话，需要先识别出用户本人的声音
- 分析结果要具体到词句级别（指出具体哪些词/句存在问题，并附带时间戳）
- 输出结构化的 Markdown/JSON 分析报告
- 提供具体、可执行的改进建议
- 首期覆盖综合维度：语音转写、文本分析、情感/语气、发音清晰度、发音标准/正音、表达结构
- 通过文件夹监控自动触发分析：用户将录音放入指定目录，系统自动生成报告
- 支持中英混合录音
- 保留每次分析的原始报告文件，架构预留趋势聚合扩展点
- 提供一次性声纹注册流程
- 声纹识别带纠偏机制：报告中标记低置信度片段，用户一键确认/否认后增量更新声纹
- 对大型录音、背景杂音和无对话片段进行预处理（VAD、降噪、按自然间断点切分）

# Non-goals

- 首期不实现实时录音采集
- 不构建用户账户系统或多租户服务
- 不替代专业演讲教练的人工反馈
- 首期不实现趋势 Dashboard，只保留可汇总的历史报告数据

# Acceptance examples

- 用户完成一次性声纹注册后，系统将一段包含多人对话的录音放入监控目录
- 系统锁定用户声音，过滤其他说话人
- 生成报告，问题定位具体到词句和时间戳（如“03:12 处连续使用 3 次‘然后’，建议替换为……”）
- 报告覆盖：转写文本、填充词、语速、情感/语气、发音清晰度、发音标准/正音、表达结构
- 对中英混合内容能正确转写并分析
- 系统保留每次报告，便于后续扩展趋势分析
- 当系统对某段说话人身份不确定时，在报告中提供“这是我/这不是我”的校正入口；用户校正后声纹模型得到更新
- 1-2 小时的长录音能在自然不说话的间断点被切分成合理大小的片段处理，不依赖固定时长
- 发音标准维度能指出具体字词或音素的不标准读音（如“05:12 ‘项’字声调疑似偏差”），并给出练习建议

# Constraints and invariants

- 优先本地处理，保护录音隐私
- 分析结果可解释，避免黑箱评分
- 首期实现 MVP，后续可扩展更多维度
- 声纹数据本地存储，不上传云端

# Decisions

- D1: 分析维度 = 综合维度（转写文本 + 情感/语气 + 发音清晰度 + 发音标准/正音 + 结构分析）
- D2: 交互方式 = 文件夹监控 + 自动生成报告
- D3: 语言支持 = 中英混合
- D4: 历史追踪 = 保留原始报告文件，架构预留趋势聚合扩展点
- D5: 多人对话 = 预先录入声纹，分析时锁定用户声音并过滤其他说话人
- D6: 分析粒度 = 词句级别，附带时间戳
- D7: 声纹纠偏 = 报告标记低置信度片段，用户一键确认/否认，增量更新声纹
- D8: 长录音处理 = 1-2 小时录音按自然不说话间断点切分，片段大小在合理处理区间内可变
- D9: 发音标准/正音分析 = 增加“发音是否标准/正音”维度，结合 ASR 置信度和音素对齐标记具体字词或音素问题，并给出练习建议
