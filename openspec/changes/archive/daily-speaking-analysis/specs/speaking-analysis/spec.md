# OpenSpec Delta: 日常录音分析工具

## 变更范围

本次变更实现一个本地运行的日常录音分析工具 MVP。用户将录音放入监控目录后，系统自动识别用户本人的声音，并针对该声音生成词句级别的分析报告。

## 新增/修改的规格

### S1: 输入触发
- 系统监控 `input/` 目录。
- 支持音频格式：WAV、MP3、M4A、FLAC。
- 新增文件自动触发分析流水线。

### S2: 音频预处理
- VAD 检测语音区间，去除长时间静音和背景无声段。
- 轻量级降噪，降低背景杂音。
- 按自然不说话间断点切分，片段时长 10 秒 - 5 分钟。

### S3: 声纹注册与识别
- 一次性声纹注册：用户提供 30-60 秒纯本人语音。
- 声纹特征本地保存到 `voiceprint/`。
- 分析时通过说话人分离 + 声纹匹配锁定用户声音，过滤其他说话人。
- 低置信度片段在报告中标记 `[?]`，供用户确认/否认。

### S4: 语音转写
- 使用 faster-whisper 本地模型。
- 支持中英混合识别。
- 输出带时间戳的词/句级别结果。

### S5: 多维度分析
- **文本分析**：填充词、重复词/短语、过长句子、逻辑连接词使用。
- **音频特征**：语速（字/词每分钟）、停顿、音量/能量变化、发音清晰度。
- **情感/语气**：情绪类别（中性、积极、紧张、疲惫等）、语气起伏。
- **发音标准/正音**：结合 ASR 置信度、音素/拼音对齐，标记疑似不标准读音，给出练习建议。

### S6: 报告输出
- 每个录音生成同文件名的 Markdown + JSON 报告。
- Markdown 面向阅读：摘要、各维度评分、具体问题、时间戳、改进建议。
- JSON 面向后续趋势聚合：结构化发现、元数据、原始时间戳。
- 报告保存到 `output/`。

### S7: 声纹纠偏
- 报告列出低置信度片段，提供“这是我”/“这不是我”入口。
- 用户确认后，片段特征作为正面样本增量更新声纹。
- 用户否认后，片段作为负面样本排除。

### S8: 错误处理
- 音频损坏：记录错误并跳过。
- 模型加载失败：给出明确提示。
- 无语音：报告为空并提示检查录音质量。
- 未注册声纹：提示用户先执行注册流程。

## 验收标准

- [ ] 完成一个可运行的分析流程。
- [ ] 使用示例录音验证报告内容符合预期。
- [ ] 验证文件夹监控能自动触发分析。
- [ ] 验证多人对话场景下能正确聚焦到用户声音。
- [ ] 验证问题定位能具体到词句和时间戳。
- [ ] 验证声纹校正能更新识别模型。
- [ ] 验证长录音和含杂音录音能被正确预处理。
- [ ] 验证发音标准维度能标记低置信度或疑似错读音素/字词，并给出可执行的练习建议。

## 依赖

- 需要本地 Python 3.10+ 环境。
- 需要下载 faster-whisper、pyannote.audio / speechbrain、emotion2vec 等模型。
- 需要足够的本地存储和内存。
